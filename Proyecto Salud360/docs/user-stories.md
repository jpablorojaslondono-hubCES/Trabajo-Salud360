# Historias de Usuario

## US-01: Acceso a la plataforma
Como usuario quiero iniciar sesión para acceder de forma segura a mi información.

### Criterios de aceptación
- El usuario puede introducir sus credenciales.
- El sistema informa si las credenciales no son válidas.
- El usuario autenticado accede a su área principal.

## US-02: Gestión del perfil
Como usuario quiero consultar y actualizar mis datos básicos de salud.

### Criterios de aceptación
- El usuario puede visualizar sus datos.
- El usuario puede editar los campos permitidos.
- Los cambios se guardan correctamente.

## US-03: Registro de indicadores
Como usuario quiero registrar indicadores de salud para realizar seguimiento.

### Criterios de aceptación
- El usuario puede introducir un indicador y su fecha.
- El sistema valida los datos obligatorios.
- El registro aparece en el historial.

## US-04: Resumen de salud
Como usuario quiero visualizar un resumen de mis indicadores recientes.

### Criterios de aceptación
- Se muestran los datos más recientes.
- La información es comprensible.
- El resumen se actualiza después de guardar un registro.
