# Salud360

## Descripción
Salud360 es una plataforma orientada a centralizar el seguimiento y la gestión de información relacionada con la salud.

## Objetivos
- Organizar la información de los usuarios.
- Facilitar el seguimiento de indicadores de salud.
- Proporcionar una experiencia sencilla y accesible.

## Estructura del repositorio
- `docs/`: documentación del producto, historias de usuario y sprints.
- `src/`: código fuente de la aplicación.

## Plan de trabajo
El desarrollo se organizará en tres sprints:
1. Definición y configuración inicial.
2. Implementación del flujo principal.
3. Validación, mejoras y preparación de entrega.
