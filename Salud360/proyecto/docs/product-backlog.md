## 🟣 ÉPICA 1. Registro de Usuario

### 🔵 FEATURE: Crear cuenta

- 🟢 Como paciente nuevo, quiero crear una cuenta con mis datos personales (nombre, apellido, documento, celular, correo, dirección) para poder acceder a los servicios de la plataforma de salud.
- 🟢 Como usuario, quiero aceptar la política de tratamiento de datos personales al registrarme, para que la app cumpla con la normatividad de protección de datos en salud.

### 🔵 FEATURE: Inicio de sesión

- 🟢 Como usuario registrado, quiero iniciar sesión con mi correo/documento y contraseña para acceder de forma segura a mi cuenta.
- 🟢 Como usuario nuevo, quiero verificar mi cuenta con un código enviado a mi correo o celular, para confirmar que mis datos de contacto son válidos.
- 🟢 Como usuario, quiero recuperar mi contraseña olvidada, para no perder el acceso a mi historial médico.

---

## 🟣 ÉPICA 2. Pagos

### 🔵 FEATURE: Seleccionar método de pago

**▸ Transferencia**
- 🟢 Como paciente, quiero pagar mi cita por transferencia bancaria, para completar el pago desde mi entidad financiera.

**▸ Tarjeta débito / crédito**
- 🟢 Como paciente, quiero pagar con tarjeta de crédito o débito, para completar el pago rápidamente en línea.

**▸ Efectivo**
- 🟢 Como paciente, quiero elegir pagar en efectivo en el sitio, para pagar presencialmente el día de mi cita.

### 🔵 FEATURE: Comprobantes y reembolsos

- 🟢 Como paciente, quiero recibir un comprobante de pago, para tener constancia de la transacción.
- 🟢 Como paciente, quiero ver mi historial de pagos y descargar facturas, para mis registros personales.
- 🟢 Como paciente, quiero solicitar un reembolso si cancelo dentro de los tiempos permitidos, para recuperar mi dinero.

---

## 🟣 ÉPICA 3. Historia Clínica (Atención Médica)

### 🔵 FEATURE: Registro y consulta de historia clínica

- 🟢 Como médico, quiero registrar la información clínica del paciente durante la consulta, para mantener un historial completo de su atención.
- 🟢 Como paciente, quiero consultar mi historia clínica, para tener acceso a mi información médica.

### 🔵 FEATURE: Órdenes médicas

- 🟢 Como médico, quiero emitir órdenes médicas (medicamentos, exámenes o recomendaciones) al finalizar la consulta, para que el paciente conozca los siguientes pasos de su tratamiento.
- 🟢 Como paciente, quiero ver y descargar mis órdenes médicas, para gestionar mis medicamentos y exámenes.

### 🔵 FEATURE: Resultados y atención virtual

- 🟢 Como médico, quiero adjuntar resultados de exámenes al historial del paciente, para centralizar su información.
- 🟢 Como paciente, quiero recibir una notificación cuando mis resultados estén listos, para acceder a la información de manera oportuna.
- 🟢 Como paciente, quiero acceder a una videollamada con mi médico en la fecha programada, para recibir la atención virtual.

---

## 🟣 ÉPICA 4. Solicitud de Cita

### 🔵 FEATURE: Buscar y agendar cita

- 🟢 Como paciente, quiero buscar médicos por especialidad, para encontrar la atención que necesito.
- 🟢 Como paciente, quiero elegir el tipo de atención (virtual o presencial) al agendar, para recibirla en la modalidad que prefiero.
- 🟢 Como paciente, quiero ver la disponibilidad de horarios de un profesional, para elegir el que se ajuste a mi tiempo.

### 🔵 FEATURE: Verificación de cita

- 🟢 Como paciente, quiero recibir la confirmación de mi cita con fecha, hora, profesional y valor a pagar, para verificar que todo es correcto antes de finalizar.

### 🔵 FEATURE: Modificación de cita

- 🟢 Como paciente, quiero modificar la fecha u hora de una cita ya agendada, para ajustarla si cambia mi disponibilidad.

### 🔵 FEATURE: Cancelación de cita

- 🟢 Como paciente, quiero cancelar una cita agendada, para liberar el espacio si ya no puedo asistir.

### 🔵 FEATURE: Recordatorio de la cita

- 🟢 Como paciente, quiero recibir un recordatorio de mi cita (por SMS, correo o notificación push), para no olvidarla.

---

## 🟣 ÉPICA 5. Seguridad y Cumplimiento

### 🔵 FEATURE: Consentimiento y privacidad

- 🟢 Como paciente, quiero otorgar mi consentimiento informado antes de una consulta, para autorizar el tratamiento de mi información médica.
- 🟢 Como paciente, quiero consultar la política de privacidad y tratamiento de datos, para entender cómo se usa mi información.

### 🔵 FEATURE: Control de acceso

- 🟢 Como administrador del sistema, quiero definir quién puede ver la historia clínica de un paciente, para proteger la confidencialidad de su información.
